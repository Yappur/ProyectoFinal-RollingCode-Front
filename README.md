🏋️ Sistema de Gestión de Turnos para Gimnasios

Este es mi proyecto final para la academia Rolling Code. Se trata de un sistema de gestión de turnos diseñado para gimnasios, con un CRUD completo para administrar reservas de manera eficiente.

🚀 Características

✅ Registro, edición y eliminación de turnos
✅ Visualización personalizada de turnos por usuario
✅ Administración exclusiva de clases para administradores
✅ Almacenamiento de datos en Base de Datos
✅ Interfaz intuitiva y responsive con Bootstrap y CSS
✅ Efectos visuales modernos con combinación de colores grises y naranjas

📦 Instalación y ejecución

Clona el repositorio:

git clone https://github.com/Yappur/ProyectoFinal-RollingCode-Front.git

Instala las dependencias:

npm install

Inicia la aplicación:

npm start
